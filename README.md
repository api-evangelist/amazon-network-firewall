AWS Network Firewall is a stateful, managed, network firewall and intrusion detection and prevention service for your virtual private cloud (VPC). It enables you to filter traffic at the perimeter of your VPC with a flexible rules engine with support for thousands of custom rules.

**Areas:** AWS · Firewall · Intrusion Detection · Network Security · VPC

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Amazon Network Firewall: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
